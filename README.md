# Crimson Uplink

Sources → idea bank → drafter → Telegram approval → publish (LinkedIn, Dev.to, X).

Multi-user, bring-your-own-keys. Next.js + Tailwind + Firebase.

## Structure

- `apps/web` — Next.js dashboard (pipeline, drafts, analytics, settings)
- `PRODUCT.md` — vision, scope, MVP tradeoffs (next commit)
- `docs/` — runbooks (LinkedIn refresh, opt-outs)

## Dev

```bash
cd apps/web
npm install
npm run dev
```
